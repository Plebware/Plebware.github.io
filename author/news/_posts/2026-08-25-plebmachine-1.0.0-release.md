# PlebMachine 1.0.0 — The First Public Release.

PlebMachine has officially reached its **first public release: version 1.0.0.**

What began as an idea for a lightweight productivity layer for Linux has now become a working, installable system that has been **tried and tested on multiple machines**.

## 🚀 PlebMachine 1.0.0.

PlebMachine is a state-driven productivity layer for the Linux desktop. It can change the working environment according to the user's selected state and mode, bringing together applications, wallpapers, and desktop configuration into a coordinated workspace.

The first release includes:

- **Cognitive Mode** for focused work.
- **Automatic Mode** for automated application launching and environment changes.
- **Off Mode** for returning the desktop to normal operation.
- Multiple working modes, including Author, Study, Research, Graphics, Music, Video, Developer, Accounting, Leisure, and more.
- Dynamic time-of-day wallpapers.
- Mission Control for managing PlebMachine states and modes.
- PlebMachine Tools and configuration utilities.
- Application launching and desktop environment management.

## 🧪 Tried and Tested.

PlebMachine 1.0.0 has been **tried and tested on multiple machines**, including an older Dual-Core system.

The results have been extremely encouraging. PlebMachine runs smoothly on older hardware, reinforcing one of the project's central ideas: a useful productivity environment does not need to demand modern, high-end hardware.

The Debian package is intended for **64-bit Debian-based Linux systems**, with MX Linux serving as the primary development and testing environment.

## 🔑 Download PlebMachine 1.0.0.

**[Download PlebMachine 1.0.0 — Debian Package](https://github.com/Plebware/PlebMachine/releases/download/v1.0.0/plebmachine_1.0.0_amd64.deb)**

The package is distributed through the official PlebMachine GitHub release.

## 🛠️ Installation.

After downloading the `.deb` package, install it from a terminal with:

```bash
sudo apt install ./plebmachine_1.0.0_amd64.deb
```

## 🌱 This Is Only the Beginning.

PlebMachine 1.0.0 is **not PlebMachine Final**.

It is the first public milestone of a project that will continue to evolve through testing, refinement, new integrations, improved configuration, and further development.

The goal is simple: build a practical Linux productivity layer that can adapt the desktop to the person using it — without requiring powerful hardware or unnecessary complexity.

**PlebMachine 1.0.0 is out of the workshop and ready to be used.**

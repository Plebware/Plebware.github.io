# 🏷️ PlebWare Site Stickers

A working collection of small graphics, badges and character stickers for use throughout the PlebWare website.

The idea is simple: choose a sticker, copy the HTML underneath it, and paste that small section into an article. The artwork can therefore be reused consistently by Otto, Julian, or future PlebWare contributors.

The filenames and wording can change later as the final sticker pack develops.

## 🧩 Building the Sticker Pack

This page is deliberately a working library rather than a finished catalogue. New stickers can be added as the PlebWare visual language develops.

The useful part is the little HTML block beneath each image: **copy, paste, done.**

That means a contributor does not need to remember the image path, centring code or sizing rules.

# 🏷️ Site Stickers

A small PlebWare collection of reusable stickers, badges and character graphics for use throughout the website.

This section provides the artwork together with ready-to-copy HTML snippets, so contributors can add a consistent visual marker to an article without having to recreate the image code each time.

## Sticker Library

The accompanying article contains the current stickers, temporary placeholders and copy-and-paste HTML examples.

More stickers can be added here as the PlebWare sticker pack grows.

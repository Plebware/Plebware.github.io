# 🔑 PlebMachine 1.0.0: The First Public Release.

<!-- PLEBVOX:START -->

PlebMachine 1.0.0 has officially arrived.

After months of development, testing, fixing, rebuilding and testing again, **PlebMachine is now available as a real Debian package for 64-bit Linux systems.**

PlebMachine is a lightweight, state-driven productivity layer for the Linux desktop. It brings together desktop states, working modes, application launching, wallpapers and productivity tools into one coordinated environment.

The first release includes **Cognitive Mode, Automatic Mode and Off Mode**, together with a range of working modes including Author, Study, Research, Graphics, Music, Video, Developer, Accounting and Leisure.

The Debian package has been tested on MX Linux and, importantly, on an older Dual-Core machine — where it runs smoothly. That test is especially important because PlebMachine is intended to remain lightweight and useful on older hardware rather than demanding a modern high-end computer.

## The First Release.

PlebMachine 1.0.0 is not called the final version. It is the beginning of the PlebMachine Linux project.

Future releases will continue to improve compatibility, configuration, application integration, visual presentation and the overall PlebMachine experience.

The Debian package is available from the official **PlebMachine GitHub 1.0.0 release**.

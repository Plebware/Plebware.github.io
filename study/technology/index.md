## 🧭 Technology Learning

Welcome to the **PlebWare Technology** study area.

This section is a growing learning shelf for ordinary people who want to understand, use and build with technology.

It can include:

- 🤖 Artificial Intelligence
- 🐍 Python
- 💻 Programming
- 🧠 Machine Learning
- 📊 Data Science
- 🐧 Linux
- 🔧 IT Support
- 🌐 Web Technology
- ⚙️ Automation
- 🛠️ Software Development

The aim is not to turn everyone into a computer scientist.

The aim is to make technology understandable enough for ordinary people to explore it, use it and eventually build with it.
